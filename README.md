# Formula

**让真正相关的人，开始对话。**

Formula 是面向 Web3 项目与用户的沟通平台。项目方根据链上持仓和站内互动筛选已加入用户，发送附带 BNB 奖励的首次消息；用户自主选择回复、领取奖励，并与项目继续沟通。

[访问产品](https://aformula.xyz) · [联系 Formula](https://aformula.xyz/support) · [常见问题](docs/faq.md)

## 第一次了解 Formula

一次沟通从项目方准备预算开始：筛选受众、发送首次消息，用户查看后自主回复，领取奖励，再按条件提现或继续交流。

项目方能观察发送、回复和领取情况，用实际对话评估下一次推广。普通用户无需预先充值，也无需购买代币。奖励鼓励首次回复，不代表购买、投资或好评。

## Formula 怎样运作

**项目方：**连接推广钱包并充值 BNB，筛选并选择用户，填写消息与总预算，核对后发送，在群发详情和会话中跟进。

**用户：**连接钱包并完成身份签名，查看首次消息，自愿回复后领取奖励，满足条件后提现到当前钱包。

**推荐人：**分享邀请链接建立直接邀请关系。被邀请用户成功收到群发后，按规则产生佣金，无需等待对方回复。

## 使用前需要了解

- 触达范围是已经加入 Formula 的用户，不是任意链上钱包。
- 钱包数据有助于筛选相关受众，不等于独立真人认证。
- 预算包含渠道佣金。成功发送后的奖励不可撤回，不因未回复而退款。
- 消息、回复与领取在站内完成，充值与提现才上链。
- 登录只验证地址归属，不请求资产转移授权；充值预算由平台托管，存在托管和运行风险。
- 不保证收到消息、固定收益、回复率或转化率。费率、门槛、网络与开放范围以产品实际页面为准。
